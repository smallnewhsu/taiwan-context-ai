# T51～T80朗讀台詞與繁中語意對照

## 台語（T51～T60）

| 編號 | 朗讀台詞 | 繁中字面意思 |
|---|---|---|
| T51 | 阿媽，你食飽未？若猶未，就轉來阮兜食。 | 阿嬤，你吃飽了嗎？如果還沒，就回來我們家吃。 |
| T52 | 菜佇電鍋內底，轉來家己挾，莫閣食泡麵。 | 菜在電鍋裡，回來自己夾，不要再吃泡麵。 |
| T53 | 我今仔日會較晏轉去，毋免等我食暗頓。 | 我今天會比較晚回去，不用等我吃晚餐。 |
| T54 | 阿爸，我拜六早起欲出門，暗時才會轉來。 | 爸爸，我星期六早上要出門，晚上才會回來。 |
| T55 | 彼項物件傷貴，我這馬無欲買。 | 那個東西太貴，我現在不想買。 |
| T56 | 明仔載早起八點愛去病院，毋通慢到。 | 明天早上八點要去醫院，不要遲到。 |
| T57 | 火車可能會誤點，我毋知六點進前敢會到。 | 火車可能會誤點，我不知道六點以前能不能到。 |
| T58 | 這包藥睏進前干焦會使食一粒，毋通加食。 | 這包藥睡前只能吃一顆，不要多吃。 |
| T59 | 一个人六百五十箍，無包括啉的。 | 每個人六百五十元，不包含飲料。 |
| T60 | 相片會使留咧，毋通囥佇網路頂懸。 | 照片可以留著，不要放到網路上。 |

| 編號 | 朗讀台詞 | 繁中字面意思 |
|---|---|---|
| T61 | 阿婆，你食飽吂？吂食就轉來屋下食飯。 | 阿嬤，你吃飽了嗎？還沒吃就回家吃飯。 |
| T62 | 菜在電鑊肚，轉來自家挾，毋好又食泡麵。 | 菜在電鍋裡，回來自己夾，不要又吃泡麵。 |
| T63 | 𠊎今晡日會較夜轉屋下，毋使等𠊎食夜。 | 我今天會比較晚回家，不用等我吃晚餐。 |
| T64 | 阿公，𠊎禮拜六朝晨愛出門，暗晡正會轉來。 | 阿公，我星期六早上要出門，晚上才會回來。 |
| T65 | 該隻東西忒貴，𠊎這下毋想買。 | 那個東西太貴，我現在不想買。 |
| T66 | 天光日朝晨八點愛去醫院，毋好遲到。 | 明天早上八點要去醫院，不要遲到。 |
| T67 | 火車可能會慢到，𠊎毋確定六點以前做得著無。 | 火車可能晚到，我不確定六點以前能不能到。 |
| T68 | 這包藥睡以前淨做得食一粒，毋好加食。 | 這包藥睡前只能吃一顆，不要多吃。 |
| T69 | 一儕人六百五十箍，毋包飲料。 | 每個人六百五十元，不包含飲料。 |
| T70 | 這張相片做得留等，毋好放到網路頂。 | 這張照片可以留著，不要放到網路上。 |

## 越南語（T71～T80）

| 編號 | 朗讀台詞 | 繁中字面意思 |
|---|---|---|
| T71 | Bà ơi, con ăn rồi, bà đừng chờ con ăn cơm nhé. | 阿嬤，我吃過了，您不用等我吃飯。 |
| T72 | Thuốc này chỉ uống một viên trước khi ngủ, đừng uống thêm. | 這個藥睡前只能吃一顆，不要多吃。 |
| T73 | Hôm nay con sẽ về muộn, khoảng chín giờ mới về đến nhà. | 我今天會晚回家，大約九點才到家。 |
| T74 | Thức ăn ở trong nồi cơm điện, về nhà thì tự lấy ăn nhé. | 食物放在電鍋裡，回家後自己拿來吃。 |
| T75 | Sáng mai lúc tám giờ chúng ta phải đến bệnh viện. | 明天早上八點，我們必須到醫院。 |
| T76 | Tôi chưa chắc mình có thể đến trước sáu giờ. | 我還不確定能不能在六點前抵達。 |
| T77 | Mỗi người trả sáu trăm năm mươi Đài tệ, chưa bao gồm đồ uống. | 每個人支付六百五十元新臺幣，不包含飲料。 |
| T78 | Tài khoản này chỉ được xem dữ liệu, không được sửa hoặc tải xuống. | 這個帳號只能查看資料，不能修改或下載。 |
| T79 | Sau khi gửi đơn đăng ký, bạn không thể đổi tên. | 報名表送出後，不能更改姓名。 |
| T80 | Thứ Sáu tuần này tôi phải đi làm, đến Chủ nhật tôi mới về nhà. | 這個星期五我必須工作，星期日才回家。 |
