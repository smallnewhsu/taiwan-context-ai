# 語你傳心 v0.2.3 最終評測報告

## 1. 評測目的

本評測驗證「語你傳心」表達改寫模組能否在不改變原意的前提下，依溝通對象、語氣與臺灣使用情境調整文字，並比較v0.1與v0.2.3在安全性、人工品質、LLM候選採用率及GPU延遲上的差異。

## 2. 評測設定

- 本機模型：Ollama `qwen2.5:3b`
- 運算裝置：NVIDIA GeForce RTX 4050 Laptop GPU
- Ollama處理器：100% GPU（CUDA v12）
- 評測案例：12案
- 自動檢查：必要概念、數字、否定、限制語氣、台語詞彙、自然慣用詞、陳述／指令一致性及省略資訊保護
- 人工評分：1位評分者，採1–5分量尺
- 人工面向：語意保真、對象與語氣適切性、自然度

## 3. 最終技術結果

|---|---:|---:|---:|

## 5. 版本修正歷程

| 問題 | 修正方式 | 最終處理 |
|---|---|---|
| 情境中的「阿嬤」被判定為新增人物 | 允許情境已明示的稱謂 | 安全候選可採用 |
| `3／三`、`2／兩`等格式被判定為數字改變 | 加入等值數字正規化 | 安全候選可採用 |
| `請勿`未被辨識為否定詞 | 擴充否定標記 | 安全候選可採用 |
| `能不能`被誤判為獨立的`不能` | 使用邊界規則判定限制詞 | 避免誤回退 |
| `今仔日`被改為不自然詞彙 | 台語關鍵詞保護 | 安全回退 |
| 原句未說明完成項目，候選新增「工作」 | 省略受詞保護 | 安全回退 |
| 自然的「傳給」被改為「傳遞給」 | 自然慣用詞保護 | 安全回退或保留自然詞 |
| 已改期的事實被改成要求對方調整會議 | 陳述轉指令保護 | 安全回退 |
| `不能買`被改成不自然的`買不了` | 撤回`不了`限制詞等價設定 | 安全回退 |

## 7. 研究限制與後續工作

- 本次僅12個先導案例，尚不足以代表所有臺灣溝通情境。
- 僅1位評分者，尚未評估評分者間一致性。
- 模型在`temperature=0`下仍可能因執行環境產生候選波動，因此正式部署仍須保留安全回退。
- 下一階段應擴充至至少30案、2位以上獨立評分者，並增加長輩、醫療提醒、職場、金額限制與台語混合語句。
- v0.2.3的規則由錯誤分析逐步建立；新增規則時必須使用獨立驗證集，避免只對現有12案過度擬合。
