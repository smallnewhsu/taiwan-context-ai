# 台語 LoRA 在地化調適與部署驗證

## 1. 目的

本次工作以數位發展部數位產業署開源的 Taiwan Tongues ASR CE 為基礎，針對生活情境台語辨識進行 LoRA 參數高效調適，並建立訓練、獨立測試、格式轉換、正式路由與安全確認的完整驗證流程。

本專案沒有以測試逐字稿重新訓練模型，也沒有因個別測試結果修改凍結測試集。

## 2. 訓練設定

| 項目 | 設定 |
|---|---:|
| 基礎模型 | Taiwan Tongues ASR CE pretrained v1.0 |
| 調適方式 | LoRA |
| 台語訓練樣本 | 3,000 筆 |
| 驗證樣本 | 200 筆 |
| 訓練步數 | 300 steps |
| Learning rate | 3e-5 |
| LoRA rank / alpha | 8 / 16 |
| 隨機種子 | 42 |
| 最終訓練 loss | 1.2672 |
| 驗證 loss | 1.3702 |
| 訓練時間 | 約 5,813 秒 |
| 峰值 GPU 保留記憶體 | 約 5.16 GB |

訓練資料經語言與文字品質檢查。台語資料掃描 31,482 筆，排除非目標語言 2,794 筆及文字損壞 1,100 筆後，建立 27,083 筆訓練資料與 505 筆驗證資料；本次 v3 實驗從中固定抽取 3,000 筆訓練資料及 200 筆驗證資料。

## 3. 獨立凍結測試設計

最終測試集為 T81–T100，共 20 筆、2 位說話者。測試集在 v3 訓練前完成凍結，並以 manifest 保存檔案雜湊；逐字稿與訓練資料的完全字串重複數為 0。

凍結證據已保存於 Git commit `802d016`（Freeze independent Taigi holdout before v3 training）。重新錄製的 T96、T97 僅作診斷，不取代原始凍結案例，也不納入正式指標。

## 4. LoRA 模型結果

### 4.1 開發案例

在 T51–T60 開發案例中，v3 的 Micro CER 由 81.46% 降至 70.20%，相對降低 13.82%。此結果用於確認訓練方向，不作為最終泛化能力主張。

### 4.2 獨立凍結測試

| 指標 | 基礎模型 | 台語 LoRA v3 | 差異 |
|---|---:|---:|---:|
| Macro CER | 72.43% | 65.63% | -6.80 個百分點 |
| Micro CER | 71.93% | 65.61% | -6.32 個百分點 |
| 總錯誤字數 | 205 | 187 | -18 |
| 個案結果 | — | 9 改善、7 不變、4 退步 | — |

Micro CER 相對降低 8.78%。三次重複執行的 CER、錯誤字數及逐字輸出一致，顯示結果具有重複性。

## 5. CTranslate2 正式部署驗證

為接入現有 faster-whisper 服務，LoRA 權重先合併為 Hugging Face 模型，再轉換為 CTranslate2。正式部署採 Float16，並保留 INT8 Float16 作比較。

### 5.1 PEFT 與合併模型檢查

單一路徑合併驗證中，20 筆有 18 筆與 PEFT 輸出完全一致；合併模型 Micro CER 為 67.02%，較 PEFT 的 65.61%增加 1.40 個百分點。因此，專案沒有只依據權重合併成功就直接上線，而是進一步以正式雙路徑流程進行部署驗收。

### 5.2 正式雙路徑流程

正式流程對每筆語音產生「無提示」與「台語提示」兩個候選，再由 Taiwan Context Engine 根據信心、詞彙與候選差異選擇結果，必要時要求使用者確認。

CT2 Float16 在 T81–T100 連續執行三次：

| 指標 | Run 1 | Run 2 | Run 3 | 摘要 |
|---|---:|---:|---:|---:|
| Macro CER | 66.00% | 66.00% | 66.00% | 完全一致 |
| Micro CER | 65.61% | 65.61% | 65.61% | 完全一致 |
| 總錯誤字數 | 187 | 187 | 187 | 完全一致 |
| API 錯誤 | 0 | 0 | 0 | 0/60 |
| 需確認案例 | 16 | 16 | 16 | 48/60 |
| 雙路徑平均時間 | 1.5376 秒 | 1.5784 秒 | 1.5634 秒 | 平均 1.5598 秒 |

三次時間的樣本標準差約為 0.0207 秒。以上時間不含服務首次載入模型的冷啟動時間。

### 5.3 Float16 與 INT8 Float16

兩種格式的整體 Micro CER均為65.61%，錯誤字數均為187。20筆中18筆輸出相同，T90與T99文字不同但個別CER相同。RTX 4050 Laptop GPU實測Float16雙路徑平均1.5376秒，INT8 Float16為1.6547秒，因此正式路由採用Float16。

## 6. 語意安全與失敗案例

T90與T99均屬明顯誤辨案例，但兩個候選的信心皆低於安全門檻：

| 案例 | 原始信心 | 提示信心 | 系統處理 |
|---|---:|---:|---|
| T90 | -0.4391 | -0.5009 | 要求使用者確認 |
| T99 | -0.7524 | -0.9062 | 要求使用者確認 |

系統仍顯示候選內容供人工核對，但不將低信心結果直接視為可靠答案。這項設計用於區分「模型有輸出」與「輸出可安全使用」。

## 7. 語言條件路由

| 語言 | 正式模型 |
|---|---|
| 台語 | Taiwan Tongues ASR CE＋台語 LoRA（CT2 Float16） |
| 客語 | Taiwan Tongues ASR CE 基礎模型 |
| 國語／混合語言 | Taiwan Tongues ASR CE 基礎模型 |
| 越南語 | Whisper Turbo |

台語模型以獨立環境變數指定，不覆蓋原始模型。系統切換台語與其他Taiwan Tongues路由時會釋放前一個大型模型，降低6GB GPU同時載入兩個模型造成記憶體不足的風險。

## 8. 客語模型未部署理由

客語LoRA實驗的Micro CER由57.52%上升至59.48%，相對退步3.41%；10筆中0筆改善、7筆不變、3筆退步。資料稽核亦發現目前客語訓練音檔雖為客語，但部分逐字稿偏向國語字面表達，與目標客語書寫形式不一致。

因此客語LoRA未通過部署門檻，正式系統維持基礎模型與使用者確認機制。後續須先改善客語逐字稿品質與說話者多樣性，再重新訓練及使用獨立測試集驗證。

## 9. 結論與限制

本次完成從開源基礎模型、資料品質檢查、LoRA調適、訓練前凍結測試、三次重複驗證、CTranslate2轉換到正式語言路由的完整流程。台語LoRA在獨立測試集的Micro CER相對降低8.78%，正式CT2雙路徑流程三次結果一致且API錯誤為0。

目前65.61%的Micro CER仍顯示生活台語辨識具有明顯改善空間。本結果應解讀為可重現的階段性改善，而非已解決所有台語辨識問題。後續將擴充不同年齡、性別、口音、設備與環境噪音的獨立資料，並持續保留人工確認與版本驗收機制。
