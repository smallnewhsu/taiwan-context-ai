# 視界有解 v0.1.1：本機視覺語境理解評測報告

## 1. 評測目的

本評測驗證「視界有解」在臺灣生活圖片上的物件辨識、繁體中文 OCR、情境理解、幻覺風險提示與本機 GPU 推論效能。系統使用 Ollama 執行 Gemma 3 4B，圖片最長邊縮放至 768 像素，並將結果拆分為「直接觀察」、「OCR 候選」、「情境推測」與「無法確認資訊」。圖片只在本機暫存處理，不永久保存。

## 2. 測試設定

- 測試案例：12 張
- 圖片類型：街景、店面、商品價格牌、公車站牌、飲料菜單、家電、回收公告、文化建築、社區公告、無文字物件、模糊文字與無地點證據控制圖片
- 模型：Gemma 3 4B
- 執行框架：Ollama
- 裝置：NVIDIA RTX 4050 Laptop GPU
- Context length：8192
- 評測版本：Taiwan Context AI Vision v0.1.1
- API：`POST /vision/analyze`

## 4. 人工評測結果

人工評測以1至5分進行，5分代表表現最佳；無文字或無情境輸出的不適用欄位留白。共完成12張圖片的人工檢視，其中OCR與情境合理性各有11個適用案例。

| 人工評測面向 | 平均分數 |
|---|---:|
| 物件正確性 | 4.42 / 5 |
| OCR正確性 | 4.45 / 5 |
| 情境合理性 | 4.27 / 5 |
| 幻覺安全性 | 4.50 / 5 |
| 安全呈現 | 4.33 / 5 |
| 全部有效評分平均 | 4.40 / 5 |

人工評分明顯高於嚴格自動指標。原因是兩者衡量內容不同：自動評測要求人工標註詞組完全命中，並以禁詞偵測具體幻覺；人工評測則同時考量主要內容是否可理解，以及介面是否已將低信心OCR和情境推測清楚標示。因此，人工高分可支持整體使用體驗與安全呈現，但不能用來取代40.00%的嚴格OCR召回率或16.67%的原始輸出無幻覺率。

## 6. 警告與安全攔截

| 警告類型 | 次數 | 意義 |
|---|---:|---|
| `low_confidence_ocr_requires_confirmation` | 10 | OCR候選可信度不足，不能直接採用 |
| `context_is_inference_not_fact` | 10 | 情境內容屬推測而非影像事實 |
| `low_confidence_context_requires_confirmation` | 7 | 情境推測缺乏足夠圖片證據 |
| `low_confidence_observation` | 8 | 部分物件辨識可信度不足 |

雖然原始模型僅有 16.67% 案例未命中人工設定的幻覺禁詞，但安全確認判定達到 100%。因此，本版本適合定位為「具人工確認機制的影像理解輔助工具」，不適合定位為無人監督的 OCR 或自動事實擷取系統。

## 7. 主要發現

1. **一般物件優於文字辨識。** 街道、車輛、建築、電鍋、鏡子與海岸等大型物件較容易被識別；細小物件與密集圖文表現較差。
2. **繁體中文 OCR 是主要瓶頸。** 店面招牌、手寫價格牌、站牌及分類公告容易發生形近字替換、漏字與虛構文字。
3. **模型自報信心不可單獨作為可靠性依據。** V03錯誤文字仍得到高信心，顯示需搭配人工確認或獨立 OCR 交叉驗證。
4. **控制案例驗證安全邊界。** V10能避免無文字圖片的自動確認；V11仍會對模糊區塊生成字母；V12未強行定位為臺灣，但仍產生不存在的數字。
5. **複雜圖文直接增加延遲。** V07耗時23.167秒，明顯高於無文字案例V10與V11，適合在介面中提供等待提示。

## 8. 使用限制與評測解讀

- 本次12張圖片屬小型先導測試，不代表所有臺灣生活影像。
- v0.1.1的人工標註是在v0.1先導結果後建立，因此屬於校準後錯誤稽核；後續若要宣稱泛化效能，需另以未參與提示與規則調整的獨立圖片測試。
- `hallucination_free_rate`依人工設定的明確禁詞計算，不能涵蓋所有可能的語意幻覺。
- `OCR exact text recall`採嚴格文字命中，對同義描述不給分，適合評估資訊擷取而非整體圖像描述品質。
- 圖片來源與使用授權應另行保存；原圖不應提交至公開Git儲存庫。
- 本次人工評分為單一輪評閱結果，尚未進行多位評閱者一致性分析；正式研究報告不應將其描述為具跨評閱者信度的結果。

## 9. 版本結論

「視界有解」v0.1.1已完成本機VLM、GPU推論、圖片API、前端介面、隱私處理及安全警告的端到端驗證。系統在物件與情境理解上具備輔助價值，但OCR與具體事實生成仍有明顯幻覺風險。現階段正確產品策略是保留人工確認、將OCR顯示為候選、明確區分觀察與推測，並在下一版加入獨立OCR交叉驗證，而不是直接自動採用模型文字。
