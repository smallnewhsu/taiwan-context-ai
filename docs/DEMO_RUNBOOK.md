# AI翻譯不了的台灣｜競賽Demo操作手冊

## Demo前檢查

1. 接上電源並切換Windows高效能模式。
2. 關閉占用GPU的程式。
3. 確認Ollama、FFmpeg及ASR環境可用。
4. 確認測試資料不含個人資訊。
5. 執行`start_demo.bat`並先完成一次暖機。

```bat
curl http://127.0.0.1:8000/health
curl http://127.0.0.1:8000/llm/health
curl http://127.0.0.1:8000/vision/health
ollama list
nvidia-smi
```

## 三分鐘展示順序

### 1. 登入與角色

先以一般使用者登入，說明使用者只能看到三項核心功能；管理與資料治理功能由管理者登入後操作。

### 2. 聲入其境

- 上傳國台混合語音。
- 展示逐字稿、字面意思、可能意境、判斷依據及建議回應。
- 說明人物關係證據不足時會要求確認。
- 修改內容並選擇是否授權資料使用。

### 3. 語你傳心

- 輸入：「阿嬤，我今天無法回家吃飯。」
- 選擇長輩及適合語氣。
- 展示改寫、台語表達及語意安全警告。
- 使用含數字或否定的句子，說明系統會保護關鍵條件。

### 4. 視界有解

- 上傳台灣生活圖片。
- 展示直接觀察、OCR候選、情境推測及無法確認資訊。
- 以語音詢問「她是在生氣嗎？」。
- 再以文字詢問「我應該怎麼回覆？」。
- 說明這是影像、語音與文字的連續多模態互動。

### 5. 管理中心

- 展示待審回饋及授權狀態。
- 核准一筆資料並查看審查紀錄。
- 說明只有授權、人工核准且完成去識別化的資料才能發布。

## GPU注意事項

6GB顯示記憶體環境應依序展示，不要同時送出語音、文字與圖片請求。需要釋放模型時執行：

```bat
ollama ps
ollama stop gemma3:4b
```

## 故障排除

若Ollama無法連線：

```bat
set OLLAMA_CONTEXT_LENGTH=8192
ollama serve
```

若後端無法啟動：

```bat
services\asr\asr_api\Scripts\python.exe -m uvicorn backend.api:app --host 127.0.0.1 --port 8000
```

若出現500或503，先查看後端第一個錯誤，再確認`ollama ps`與`nvidia-smi`。現場備援畫面須清楚標示為預錄結果。
