# AI翻譯不了的臺灣｜Taiwan Context AI

> 讓AI不只辨識一句話，更能理解臺灣生活中的人物關係、語境與話外之意。

Taiwan Context AI 是一套以臺灣在地溝通需求為核心的多模態AI系統，整合語音、文字與影像理解，協助不同世代、語言背景與數位能力的使用者理解訊息並安心表達。系統將人物關係、生活情境、語意安全檢查、使用者確認及人工審查納入完整流程，而不是直接把模型輸出視為唯一答案。

## 系統功能

| 模組 | 使用情境 | 主要輸出 |
|---|---|---|
| **聲入其境** | 上傳或錄製國語、台語、客語、英語、越南語及混合語音 | 辨識話語、字面意思、可能意境、判斷依據及建議回應 |
| **語你傳心** | 依長輩、晚輩、朋友、同事或不熟悉者調整表達方式 | 直接表達、安心表達及台語表達，並檢查數字、否定、限制條件與新增資訊 |
| **視界有解** | 分析紙條、公告、對話截圖及臺灣生活物件 | 可見文字、物件與場景說明、生活語境、可能意圖，以及影像後接語音或文字追問 |

一般使用者可操作三項核心功能、修正內容並確認AI輸出；管理者可進行回饋審查、授權確認、資料集發布、評測結果及服務狀態管理。

## 技術架構

```text
語音／文字／影像
        ↓
開源或開放權重模型
Taiwan Tongues ASR CE／Whisper large-v3-turbo／Gemma 3 4B
        ↓
Taiwan Context Engine
模型路由／人物關係／語境推論／語意保真／安全回退
        ↓
使用者確認與修正
        ↓
明確授權 → 人工審查 → 去識別化 → 版本化資料集
```

### 核心元件

| 元件 | 系統用途 | 執行方式 |
|---|---|---|
| **Taiwan Tongues ASR CE** | 國語、台語、客語、英語與混合語音辨識 | 本機推論 |
| **OpenAI Whisper large-v3-turbo** | 越南語語音辨識 | 透過 `faster-whisper`／CTranslate2本機推論 |
| **Gemma 3 4B** | 文字改寫、語境分析、繁體中文字面翻譯、影像理解與多模態問答 | Ollama本機推論 |
| **Taiwan Context Engine** | 語言路由、人物關係判斷、語意保真檢查、安全回退及人工確認 | 本專案自建服務 |

`faster-whisper` 是執行Whisper模型的推論框架，不是另一個語音模型。本系統越南語路徑實際使用的模型為 **OpenAI Whisper `large-v3-turbo`**，並在本機完成辨識，不呼叫OpenAI雲端API。

## 多語語音辨識

系統依使用者指定的語言選擇辨識路徑，避免越南語音被錯誤送入以臺灣語言為主的模型：

| 使用者選擇 | 辨識模型 |
|---|---|
| 國語、台語、客語、英語及混合語音 | Taiwan Tongues ASR CE |
| 越南語 | OpenAI Whisper large-v3-turbo |

越南語辨識結果會再交由Gemma 3 4B產生繁體中文字面意思，最後由Taiwan Context Engine進行語境分析、安全檢查與使用者確認。此設計保留數位發展部開源模型在臺灣語言應用中的核心角色，並補足新住民家庭、照護與公共服務場域的跨語需求。

## 相較基礎語音模型的系統擴充

| 比較項目 | 基礎ASR功能 | Taiwan Context AI |
|---|---|---|
| 語言辨識 | 產生語音逐字稿 | 依語言條件路由，並新增越南語專用路徑 |
| 繁中理解 | 以原始辨識文字為主 | 越南語逐字稿另產生繁體中文字面意思 |
| 語境理解 | 不處理人物關係與話外之意 | 提供可能意境、判斷依據及建議回應 |
| 不確定性 | 輸出單一辨識結果 | 資訊不足時要求補充關係、場合或前後文 |
| 語意安全 | 不檢查後續生成內容 | 檢查新增資訊、刪除資訊、數字、否定與限制條件 |
| 多模態互動 | 單一語音辨識 | 串接文字改寫、影像理解及影像後接語音問答 |
| 資料回饋 | 不含本專案治理流程 | 使用者授權、人工審查、去識別化及版本化發布 |

## 評測摘要

### 語音辨識

| 評測集 | 案例數 | 結果 |
|---|---:|---:|
| T22～T50多語擴充集 | 29 | 語言條件路由平均CER 36.80% |
| T51～T80多語測試集 | 30 | 整體Macro CER 48.10%、Micro CER 34.83% |
| T51～T80穩態效能 | 29筆（排除暖機） | 平均0.5995秒、P95 0.8743秒 |

T51～T80分語言結果：

| 語言 | 案例數 | 辨識路徑 | Macro CER | Micro CER |
|---|---:|---|---:|---:|
| 台語 | 10 | Taiwan Tongues ASR CE | 0.7845 | 0.7947 |
| 客語 | 10 | Taiwan Tongues ASR CE | 0.5543 | 0.5556 |
| 越南語 | 10 | Whisper large-v3-turbo | **0.1042** | **0.1054** |

在相同10筆越南語測試中，越南語Macro CER由單一路徑基準的0.7726降至0.1042，相對降低 **86.51%**。台語與客語的模型輸出可能採華語語意轉寫，與原始正字逐字稿存在書寫系統差異，因此CER反映字面序列差異，不應直接等同語意理解錯誤率。

### 文字改寫與多模態影像理解

| 項目 | 結果 |
|---|---:|
| 語你傳心36筆擴充評測，自動安全通過率 | 100% |
| 語你傳心12筆凍結獨立測試，自動首次通過率 | 83.33% |
| 語你傳心12筆凍結獨立測試，人工複核原始輸出通過率 | 91.67% |
| 使用者確認與修正後安全完成率 | 100% |
| 視界有解多模態評測案例 | 12筆 |
| 視界有解完成案例／API錯誤 | 12/12／0 |
| 視界有解自動通過率 | 91.67% |
| 回答關鍵詞召回率 | 96.43% |
| 幻覺避免率 | 100% |
| 不確定性處理正確率 | 100% |
| 人工複核通過率 | 11/12（91.67%） |
| 穩態平均端到端處理時間 | 14.10秒 |

安全回退、人工複核與使用者修正後的完成率，不等同模型首次輸出準確率。「視界有解」評測涵蓋影像理解、文字追問、圖片依據、回答相關性、語境合理性、幻覺風險與不確定性處理。完整案例、評測程式、結果及限制請見 [`evaluation/`](evaluation/)。

## 多模態互動

「視界有解」可先以影像模型擷取紙條、公告或生活圖片中的文字與場景，再接受使用者以語音或文字追問，例如「她是在生氣嗎？」或「我應該怎麼回覆？」。系統會綜合影像內容、辨識文字與追問內容產生回答，並保留資訊不足提示與使用者確認機制。

## 資料治理與開源回饋

```text
使用者修正
    ↓
明確勾選資料使用授權
    ↓
管理者人工審查
    ↓
去識別化候選資料
    ↓
版本化資料集發布
```

- 未授權內容不會加入資料集。
- 審核通過不等同自動公開，只有完成授權與去識別化的資料才能進入發布版本。
- 私人語音、圖片及未去識別化內容不提交至公開Git儲存庫。
- 評測保留測試案例、標準答案、結果與程式，以利重現及後續比較。

- Python 3.10

## 已知限制

- 台語、國台混合及客語仍需擴充不同地區、年齡與說話者資料。
- 台語與客語應增加語意保留率及人工複核，補充正字CER的限制。
- 越南語目前完成10筆錄音測試，仍需擴充不同性別、口音、年齡與噪音環境。
- 小型視覺語言模型的繁體中文OCR可能漏字或產生幻覺，輸出必須保留人工確認。
- 目前人工評測人數有限，尚未建立多評分者一致性。
- 本系統提供溝通與識讀輔助，不取代醫療、法律或其他專業判斷。
